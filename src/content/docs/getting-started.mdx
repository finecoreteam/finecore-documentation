# Getting Started

1. Set up your environment variables (e.g. https://api.finecore.co/v1, `API_KEY`)

2. Use your API key in the X-API-Key header: X-API-Key: `API_KEY`

3. Explore the endpoints organized by service in this collection

4. Review the example requests and responses for correct formatting

### Notes

- This is the v1 version of the Finecore BAAS API.

- All responses are returned in JSON format.

- Ensure your API key is kept secure and not exposed in public environments.

- Error responses will contain helpful messages and status codes.
